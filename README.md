# DualCopy

A zero-config secondary clipboard for Windows. Runs silently in the background using 0% CPU.

## Download

👉 **[Click here to download DualCopy.exe](https://github.com/svelez1129/more-copies/releases/tag/v1.0.0)**

---

## Shortcuts

* `Ctrl` + `Shift` + `C` — Copy secondary
* `Ctrl` + `Shift` + `V` — Paste secondary
* `Ctrl` + `Alt` + `P` — Pause / Resume

## Install

1. Download `DualCopy.exe`.
2. Double-click to run.

Starts automatically on boot. No installer or admin rights needed.

## Uninstall

Double-click `DualCopy.exe` while it is running and click **Yes**.
